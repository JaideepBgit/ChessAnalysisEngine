## How to Use These Games

1. Copy the entire game text (including headers)
2. Paste into the "PGN" field in the analysis interface
3. Enter the player name you want to analyze (e.g., "Player1", "Tactical_Player")
4. Click "Analyze Game"

## What to Look For

### Game 1 (Scholar's Mate)
- Very short game
- Shows how quickly mistakes can end a game
- Black's blunder on move 3

### Game 2 (Italian Game)
- Balanced opening
- Good for learning standard positions
- Shows typical middlegame plans

### Game 3 (Sicilian Defense)
- Complex tactical game
- Sharp positions
- Good for advanced analysis

### Game 4 (Queen's Gambit)
- Endgame focus
- Precise play required
- Draw by repetition

### Game 5 (King's Indian)
- Attacking chess
- Pawn storms
- Tactical complications

## Tips for Analysis

1. Start with shorter games (Game 1-2)
2. Focus on your own games for best learning
3. Compare your moves to engine suggestions
4. Pay attention to phase-specific accuracy
5. Review blunders carefully
6. Note patterns in your mistakes
